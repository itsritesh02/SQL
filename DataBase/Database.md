# Database

## 1. What is a Database?

A **Database** is an organized collection of data that allows us to **store, manage, retrieve, and update** information efficiently.

**Simple Definition:**
> A database is a place where data is stored in an organized way.

### Real-Life Example

Think of a **school register**.

Instead of writing student information on different papers, everything is stored in one register.

Similarly, a database stores data in one place.

Example:

- Student Details
- Employee Details
- Customer Details
- Product Details

---

## 2. Why Do We Use a Database?

We use a database because it helps us:

- Store large amounts of data
- Find data quickly
- Update data easily
- Delete unwanted data
- Keep data organized
- Reduce duplicate data
- Improve security

## 4. Types of Databases

### 1. Relational Database (RDBMS)

Stores data in **tables** (rows and columns).

Examples:
- MySQL
- PostgreSQL
- Oracle
- SQL Server

---

### 2. NoSQL Database

Stores data in different formats like documents, key-value pairs, graphs, etc.

Examples:
- MongoDB
- Firebase
- Cassandra

---

## 5. Database Structure

```
Database
    │
    ├── Table
    │      │
    │      ├── Rows (Records)
    │      └── Columns (Fields)
    │
    └── Another Table
```

Example:

### Students Table

| ID | Name | Age |
|----|------|-----|
|1|Ritesh|22|
|2|Rahul|21|

- Database → College
- Table → Students
- Row → One student record
- Column → ID, Name, Age

---

## 7. Database vs Table

| Database | Table |
|-----------|-------|
| Collection of tables | Collection of rows and columns |
| Stores complete data | Stores specific data |
| Can contain multiple tables | Belongs to one database |

Example:

Database: College

Tables:
- Students
- Teachers
- Courses
- Fees

### Q3. What is the difference between a Database and a Table?

**Answer:**

NoSQL Databases:

---

### Q5. What is the difference between SQL and NoSQL databases?

| SQL | NoSQL |
|------|--------|
| Stores data in tables | Stores data in documents, key-value pairs, graphs, etc. |
| Fixed schema | Flexible schema |
| Best for structured data | Best for unstructured or semi-structured data |
| Example: MySQL | Example: MongoDB |
